# Hollow — 2.5D escape prototype (Godot 4.7 C# + Blender MCP)

## Step 1 — Launch Blender (once per session)
Start it detached in the background: `"D:/Blender 5.2/blender.exe" --online-mode &`, then verify the MCP connection (port 9876) responds.

## Step 2 — Create the 3 assets in Blender via MCP, export as .glb to `res://assets/`
- **ball.glb** — UV sphere, r = 0.4, smooth shaded, warm emissive material.
- **block.glb** — 1×1×1 cube (tiny bevel), pale neutral material.
- **block_hollow.glb** — the same cube reduced to its 12 edges (thin cylinders along each edge, ~0.04 thick), ghostly emissive material.
Walls/gates reuse `block.glb` tinted in Godot — no extra assets needed.

## Step 3 — Godot setup
- Add input map to `project.godot`: WASD move, Space jump, R restart.
- Minimal `Main.tscn` (single root node + `Main.cs`); everything else is built in code — far more robust to hand-write for a jam.

## Step 4 — C# scripts (the whole game)
- **LevelBuilder.cs** — builds the level at `_Ready()`: a grid of floor cubes inside radius ~20 (≈1300 blocks, fine for Jolt), three ring walls at r ≈ 8 / 14 / 20. Each ring = low 1-block-high walls (jumpable) mixed with 2-high segments, plus 1–2 wide gate gaps at fixed angles. Registers every block (position, mesh, body) sorted by distance-from-center for the hollowing system. Spawns the ball at r ≈ 5.
- **Player.cs** — CharacterBody3D ball: WASD relative to the camera's fixed yaw, acceleration, jump, gravity; the mesh visually rolls with velocity. Speed/jump exported for tuning.
- **Nothingness.cs** — an expanding dark disc with a glowing edge at the center. Radius grows at ~0.5 blocks/s (slightly faster each ring). When it reaches a block: swap mesh to the hollow wireframe (collision still on), start the 3-second fuse, then the block is destroyed — so you have 3s to jump off. Randomized ~0.3s stagger per block for a wave feel.
- **CameraRig.cs** — angled top-down camera (offset ≈ (0, 13, 9)), smoothly following the ball.
- **Main.cs + HUD** — dark moody WorldEnvironment + fog; shows current ring, run timer, "You escaped!" when the ball gets beyond the outer wall, "Hollowed." when the ball falls below the floor; R restarts the scene at any time.

## Step 5 — Build & verify
`dotnet build`, fix any compile errors, then launch the game (or hand you the F5 instruction if the editor binary isn't on PATH). All tunables (growth speed, fuse time, move/jump speed, ring radii) are exported inspector parameters for quick iteration.

**Goal of the test:** feel whether the "outrun the nothingness across crumbling hollowing rings" loop is fun.
